Audio8-ASR-Infinite · web demo · user manual

Everything runs on the board (NPU for the models, CPU for audio front end, VAD and decoding). This page is served by the board; open it from any browser on the same network. Close this window with Esc, the × button or a click outside.

1. Quick start

  1. Pick a video in the video list (left, under the player).
  2. Optionally move the playhead to where you want to begin (the button shows Start at mm:ss).
  3. Press Start. The video plays from that point with sound and the transcript appears on the right while it plays.
  4. Pause the video to pause the transcription; press play to continue. Press Stop to end the run.
  5. Use Copy or Export (top right of the transcript) to take the text.

2. Screen layout

  • Top left – video player and the controls.
  • Top right – live transcript. The newest words appear in light blue and settle to white.
  • Bottom bar – live metrics: run statistics, Silero VAD, board DRAM, RTF and end of turn.
  • Header – current audio clock and context mode, model load time, run state (Ready / Transcribing / Done / Stopped).

4. VAD settings

SettingDefaultWhat it does
Silero threshold0.5Speech probability above which Silero VAD counts a frame as speech (start of the silence gate). Higher = less likely to open on applause, but may open slightly later.
Look-ahead (s)0.5How much audio before the detected speech start is kept, so the first word is not cut. It does not delay text while someone is talking.
End-of-turn horizon2 sWhich prediction drives the end-of-turn meter and paragraphs: probability that nobody speaks within the next 0.5 / 1 / 2 / 3 s.
End-of-turn threshold0.6Above this value the speaker is considered finished. Raise it (e.g. 0.7) if paragraphs are too short.
ParagraphsOnStarts a new paragraph in the transcript at each end of turn.

Silero threshold and look-ahead apply from the next Start and are shared by everyone using the board. The end-of-turn settings apply immediately and are stored only in your browser.

5. Metrics

MetricMeaning
PositionVideo time the transcription has reached.
First wordTime from Start until the first word appeared.
Step timeMedian NPU + CPU time per model step (one step per audio clock: 160 or 80 ms).
Words / CharactersSize of the transcript (characters when transcribing Chinese).
Silero VADSpeech probability (bar; the yellow mark is the threshold), Speech / Silence, and the state of the gate: "waiting for speech" or "gate open" with the seconds silenced before speech.
Board DRAMMemory used on the whole board over the last minute. It stays flat during long runs.
RTFReal-time factor = step time ÷ clock. Below 1 means faster than real time (dashed line = 1.0). Bold line: 8-token average; thin line: every token.
End of turnThe model's own end-of-turn prediction for the four horizons (selected one in bold, threshold dashed); the bar shows the selected horizon.

6. Good to know

  • Unlimited length. The model keeps the last 30 s of context ("rolling 30 s context" in the header), so memory and speed stay constant for any video length.
  • Start anywhere. A start or jump begins a fresh session at that point; the first words of a sentence cut by the jump may be missing.
  • Long pauses. If the model stays silent although speech has resumed, it is restarted automatically and re-listens to the last seconds (a new paragraph starts there).
  • Latency. Words appear about 1 s after they are spoken (the model listens 480 ms ahead by design).
  • One run at a time. The board serves one transcription; a Start from any browser replaces the current run. Audio clock, language and gate settings are shared.
  • The first Start may need a click before the browser allows sound.

7. Troubleshooting

SymptomWhat to do
"Disconnected" in the headerThe page lost the board connection: check the network and reload the page.
"Incomplete" after an audio delivery failurePlayback stops on a network error, failed HTTP request or 10-second request timeout. Reconnect, seek to before the interruption and press Start for a new transcription. Copied/downloaded text is marked incomplete until then.
"Model failed" or model reload failedThe transcript is incomplete and Start is disabled. Read the error, click Reload model and wait. If loading fails, fix the reported model/runtime problem and retry. Successful loading keeps playback paused and preserves the previous transcript; seek to before the failure and press Start for a new transcription.
No soundCheck the browser / system volume and the player's volume control; press Start again.
Upload failed: no audio trackThe file has no audio; use a video with sound, preferably MP4 (H.264 + AAC).
No text while the video playsThe page sends the sound it plays to the board: keep the player unmuted with some volume.
Video does not play after uploadYour browser cannot decode the format; convert it to MP4 (H.264 + AAC).
Model load failed after an audio clock / language changeThe previous setting is restored when possible. If the model remains failed, use Reload model; Start stays disabled until loading succeeds.
Stray words before the speaker startsMake sure Silence gate is on; raise the Silero threshold slightly.
Loading models…
The board is reloading the NPU models, this takes a few seconds.
