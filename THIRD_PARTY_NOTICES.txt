Audio8-ASR-Infinite
==================

This repository contains an on-device speech recognition package for Qualcomm NPUs: a prebuilt inference library
(sdk/lib/libaudio8_asr.so) with its C header and Python binding, Python examples and a web demo.
APLUX application/business code is under Apache-2.0; proprietary SDK binaries are separately licensed.
See LICENSING.md and LICENSES/Apache-2.0.txt.

Model files
-----------
The model files (quantized QNN context binaries and host-side tensors) are not distributed in this repository; they
are downloaded separately (see models/README.md) and come with their own license terms.

Runtime (not distributed)
-------------------------
The library links against the AidLux aidlite SDK and Qualcomm QNN / QAIRT runtime libraries installed on the board.
They are not part of this repository and are covered by their own licenses.

Demo media
----------
demo/media/ holds 10-minute excerpts of recordings of public product launches (a Steve Jobs keynote, the Xiaomi 18 Pro
launch, the Smartisan OS 2013 launch) and examples/audio/ their 16 kHz audio tracks. They are included only to
demonstrate the speech recognition; all rights remain with their owners.

Model licensing boundaries
--------------------------
Separately downloaded model weights, tensors and third-party components retain their applicable licenses.
The Pandora agreement covers only proprietary contributions that APLUX has the right to license; it does not
replace upstream terms or remove existing rights. Consult the licenses and notices accompanying the model download.

ICU 70.1 code and its complete Unicode data are statically embedded in libaudio8_asr.so
for Unicode normalization and regular expressions. No system ICU package is required.
Source: https://github.com/unicode-org/icu/releases/tag/release-70-1
The complete ICU copyright, Unicode data and third-party notices accompany this SDK in LICENSES/ICU.txt.
